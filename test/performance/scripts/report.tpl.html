fortio (in-cluster) sends HTTP to the Gateway; Envoy runs coraza-proxy-wasm inline on every request. The WAF pulls its rule set from the operator's RuleSetCache via HTTP poll (~15 s interval). fortio measures the complete client-observable round-trip (loadgen → Gateway → echo → Gateway → loadgen). WAF cost = Δ latency vs. waf-off baseline, per percentile, median of repeats.

Each cell reads latency (+Δ ms, +%) — the median, then what the WAF added versus the waf-off baseline at that same percentile. The percentage is that Δ as a share of the baseline, so +100% means the WAF doubled it (not that it took 100% of baseline). Percentages differ across a row because each is measured against its own percentile's baseline.
